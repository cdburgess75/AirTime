# Visual assets for the README

Drop the files below in here and the README picks them up. Every one has a
placeholder in place already, so nothing breaks while they are missing —
GitHub just shows the alt text, which is written to describe exactly what the
shot should contain.

| File | What it should show | Size |
|---|---|---|
| `hero-device.jpg` | The radio on the bench, screen lit, clock synced. The first thing anyone sees — make it the device doing its job. | landscape, ~1600 px wide |
| `screens-triptych.png` | Three device screenshots side by side: clock face, CW copy, waterfall. Photograph the panel straight-on in even light. | ~1600 × 600 px |
| `phone-install.png` | Two phone screenshots: the AirTime icon on the home screen, and the app open full-screen. | portrait pair, ~1200 px wide |
| `status-page.png` | A desktop browser on `192.168.4.1/status`. | ~1400 px wide |

Shooting notes, learned the hard way on this project:

- The TFT is glossy. Shoot slightly off-axis with a diffuse light source, not
  a ceiling downlight directly overhead.
- Let it reach SYNCED first. A hero shot of an UNSYNCED clock undersells it,
  and the amber warning colour reads as an error to anyone who does not know
  the project.
- For the cycle bar, catch it part-filled — a full or empty bar looks static.
